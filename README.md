# ✅ To-Do List

Aplicação de lista de tarefas completa e responsiva, com persistência de dados no navegador.

---

## ✨ Funcionalidades

- Adicionar novas tarefas
- Marcar tarefas como concluídas
- Excluir tarefas
- Filtros: Todas / Pendentes / Concluídas
- Contador de tarefas pendentes
- Botão para limpar todas as tarefas concluídas
- Salvamento automático com **LocalStorage** (as tarefas permanecem mesmo após fechar o navegador)
- Interface responsiva e moderna

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
- LocalStorage
